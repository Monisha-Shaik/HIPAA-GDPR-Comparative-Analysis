# Research Application — Planned Optional Extension

This folder reserves space for an optional research application based on the verified HIPAA–GDPR comparison matrix. The application is not a required approved deliverable in the main research proposal.

A possible future direction is a Python desktop application that compares requirements, distinguishes current requirements from proposed reforms, displays supporting legal provisions, and generates source-linked comparison reports. Scope, design, and validation remain to be developed; no working application or validated compliance assessment is provided.

- `src/`: future application source code.
- `data/`: future source-traceable research data derived from the verified matrix.
- `tests/`: future validation tests.

Scenario-based assessment would require separate design and testing. Any future output would support academic comparison and would not constitute a legal or compliance opinion.
